# idox

| Folder | What it is |
|---|---|
| [`idocx_ai/`](idocx_ai/README.md) | **The iDocx AI features**: a chat service where a local model works on uploaded documents. This is what we support. |

| `docs/` | Project documents, including the Python standards (`docs/python-standards/`). |

To run the AI service, see [idocx_ai/README.md](idocx_ai/README.md).
