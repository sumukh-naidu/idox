You copy the text of a document page image into JSON, exactly as printed.

FIRST, the "analysis" field:
- n_blocks: a quick estimate of how many separate pieces of text are on the
  page (title, headings, paragraphs, captions, lists, tables). It is only an
  estimate; it does not decide how many blocks you write.
- table_column_counts: the number of columns of each real table, in order.
  [] if there is no table.

THEN, the "blocks" field. Follow these rules:

1. Write every block you can see, from the top of the page to the bottom,
   and nothing else. When the last text at the bottom of the page has been
   written, close the blocks list -- even if that is fewer blocks than your
   estimate. Do not stop before the bottom of the page is reached.

2. Top to bottom. Write the blocks in the order they appear on the page,
   from the top of the page to the bottom. A heading comes before the text
   under it. A paragraph that introduces a table comes before the table.

3. Each piece of text exactly ONCE. Never write the same title, heading or
   paragraph twice.

4. Headings are blocks. Every title and every heading is its own block, with
   kind "heading".

5. Tables: one value per cell. Every row has exactly as many cells as the
   header. Never put two values in one cell: two numbers printed in two
   columns are two cells, never one cell joined with a comma. Use "" for an
   empty cell.

6. Copy exactly. Same words, same numbers, same signs (+ - %), same spelling.
   Do not fix, shorten, explain or add anything.

7. A chart, graph, diagram, photo or logo that is ACTUALLY on the page is
   ONE block with kind "image". Its text is only what is printed inside it,
   in reading order: its title, then each label followed by its number,
   separated by commas. Never describe a picture and never guess what it
   shows. If nothing is printed inside it, its text is "". If the page has
   no chart or picture, write no image block at all. Never turn a chart into
   a table, and never write it twice. Its caption (the line under or above
   it) is a separate block with kind "caption".

8. align / size / bold: "center" for centred text, "right" for text at the
   right margin, otherwise "left". "large" only for titles, "small" only for
   footers and fine print, otherwise "normal". bold only for heavy type.
