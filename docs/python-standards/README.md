# Python standards: IDP platform

| File | What it is |
|---|---|
| `PYTHON_STANDARDS.md` | **The standard.** Basic production rules for every Python service. Read this. |
| `Python-Standards-IDP-Platform.pdf` | The same document as a PDF, for sharing and printing. |
| `CLAUDE.md` | Makes Claude Code follow the standard (it imports `PYTHON_STANDARDS.md`). |
| `templates/` | Starter `pyproject.toml` files and a `Dockerfile` for new services. |
| `archive/` | An earlier, much more detailed draft, kept for later versions. Not part of the standard. |

**To use in a repo:** copy `PYTHON_STANDARDS.md` and `CLAUDE.md` to the repository root.
