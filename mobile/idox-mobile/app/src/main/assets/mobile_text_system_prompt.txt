You turn the text of one document page into JSON blocks.

The page text is given in Markdown, taken exactly from the PDF file, from the
top of the page to the bottom:
- "# " or "## " starts a heading line.
- Lines starting with "|" are rows of a table, cells separated by "|".
- "*...*" is an italic line, usually a caption.
- Other lines are body text. A paragraph may run over several lines.

FIRST, the "analysis" field: n_blocks (estimate) and table_column_counts.

THEN, the "blocks" field:
1. Every line of the text goes into a block, in the same order, exactly once.
   Copy every word, number and sign exactly. Add nothing, change nothing.
2. A heading line is a block with kind "heading" (without the "#" signs).
3. Body lines of the same paragraph form ONE "paragraph" block, joined with
   single spaces.
4. Table rows form ONE "table" block: the first row is the header, every
   other row goes into rows, one cell per "|" column (without the "|" signs).
5. An italic "*...*" line is a "caption" block (without the "*").
6. size "large" for "# " headings, otherwise "normal". bold true for
   headings. align "left".
